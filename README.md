# Supermarket-Sales-Analysis
# Marketing Performance Dashboard: Supermarket Sales Analysis

## Project Overview

This project explores supermarket transaction data to identify customer purchasing patterns, revenue drivers, and business opportunities through data analysis and interactive visualization.
Using Python and Tableau, the analysis transforms raw transactional data into actionable business insights that support marketing, sales, and customer engagement strategies.
This project demonstrates the complete analytics workflow, including:
- Data cleaning
- Exploratory data analysis (EDA)
- Data visualization
- Dashboard development
- Business recommendations
## Business Objectives
The purpose of this analysis was to answer the following business questions:
1. Which product lines generate the highest revenue?
2. Which customer type spends the most?
3. Which payment methods contribute the most revenue?
4. How does revenue change over time?
5. Which cities generate the highest revenue?
6. Which product lines receive the highest customer ratings?
7. Is there a relationship between purchase quantity and revenue?

## Dataset

The dataset contains 1,000 supermarket transactions and includes the following variables:
| Variable | Description |
| --- | --- |
| invoice_id | Transaction identifier |
| branch | Store branch |
| city | Store location |
| customer_type | Customer classification |
| gender_customer | Customer gender |
| product_line | Product category |
| unit_cost | Cost per item |
| quantity | Number of items purchased |
| 5pct_markup | Product markup |
| revenue | Total transaction revenue |
| date | Transaction date |
| time | Transaction time |
| payment_method | Payment method |
| cogs | Cost of goods sold |
| gm_pct | Gross margin percentage |
| gross_income | Gross income |
| rating | Customer satisfaction rating |

## Exploratory Data Analysis

### Revenue by Product Line

This analysis identified the product categories contributing the highest revenue.

**Key Insight:**

Food and beverages generated the highest revenue, while health and beauty generated the lowest revenue.

---

### Revenue by Customer Type

This analysis compared spending patterns between customer groups.

**Key Insight:**

Customer segmentation revealed differences in spending behaviour that could support future marketing strategies.

---

### Payment Method Distribution

This analysis examined how customers preferred to complete transactions.

**Key Insight:**

Cash and e-wallet payments represented the largest share of total revenue.

---

### Revenue by City

This analysis compared revenue across different locations.

**Key Insight:**

Revenue varied across cities, suggesting differences in customer demand and market performance.

---

### Monthly Revenue Trends

This analysis examined changes in revenue over time.

**Key Insight:**

Monthly fluctuations revealed potential seasonal patterns that could influence inventory planning and marketing campaigns.

---

### Customer Ratings by Product Line

This analysis compared customer satisfaction across product categories.

**Key Insight:**

Product lines with higher ratings may represent opportunities for further investment and promotional activity.

---
## Business Recommendations

Based on the analysis, the following recommendations were identified:

- Prioritize high-performing product lines.

- Develop targeted campaigns for lower-performing categories.

- Expand marketing efforts in high-revenue cities.

- Improve customer engagement strategies.

- Optimize payment systems based on customer preferences.
